# Seguridad y transparencia — Núcleo CERT

**Frontend abierto:** todo el código del cliente (formularios, wizard, verificación) es público en este repositorio — es el mismo código que corre en tu navegador al usar nucleocert.com.

**Backend privado por diseño:** la lógica de servidor y credenciales de integración (Mercado Pago, SMS, email) se mantienen fuera del repositorio público, práctica estándar para evitar exposición de secretos — no por ocultar funcionamiento.

**Protección de datos:** Registro Nacional de Bases de Datos aprobado ante AAIP, legajo RL-2026-69267081-APN-DNPDP#AAIP.

**Validación de licencias:** toda operación gratuita por licencia de minería NKL se revalida contra la base del pool en el servidor — no se acepta como válido ningún dato enviado sin verificar desde el cliente.

**Reporte de vulnerabilidades:** si encontrás un problema de seguridad, escribinos antes de publicarlo — respondemos y corregimos rápido.
